# Dra. Isabella Sampaio

Site único em Next.js, personalizado a partir do template premium-vendas.

## Desenvolvimento

Requer Node.js 20.9 ou superior.

```sh
npm ci
npm run dev
```

## Vercel

Importe este repositório, selecione o framework Next.js e use a raiz do projeto. Build: `npm run build`. A Vercel configura automaticamente o domínio de produção nos metadados. Para domínio próprio, preencha `seo.url` em `data/site.ts`.
